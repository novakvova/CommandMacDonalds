# 🎨 Гайд по єдиному стилю McDonald's

## 📋 Загальний опис

Весь сайт використовує єдиний стиль з кольоровою схемою McDonald's та консистентними компонентами.

## 🎨 Кольорова схема

### Основні кольори (CSS змінні)
```css
--mcdonalds-red: #ff6b35;      /* Основний червоний */
--mcdonalds-orange: #f7931e;   /* Помаранчевий */
--mcdonalds-yellow: #ffd700;   /* Жовтий */
--mcdonalds-dark: #333333;     /* Темний текст */
--mcdonalds-light: #f8f9fa;    /* Світлий фон */
--mcdonalds-white: #ffffff;    /* Білий */
--mcdonalds-gray: #666666;     /* Сірий текст */
--mcdonalds-light-gray: #e0e0e0; /* Світло-сірий */
```

## 🧩 Глобальні компоненти

### Кнопки
```css
.btn-primary    /* Основна кнопка з градієнтом */
.btn-secondary  /* Другорядна кнопка з обводкою */
```

### Картки
```css
.card           /* Базова картка з тінню та анімацією */
```

### Заголовки
```css
.section-title  /* Заголовок секції */
```

### Градієнти
```css
.gradient-primary   /* Основний градієнт (червоний-помаранчевий) */
.gradient-secondary /* Другорядний градієнт (жовтий) */
```

### Інпути
```css
.input-primary  /* Основний інпут */
```

### Ціни
```css
.price          /* Стиль для відображення цін */
```

### Бейджі
```css
.badge          /* Бейдж для позначення статусу */
```

## 📱 Responsive дизайн

### Breakpoints
- **Desktop:** > 768px
- **Tablet:** 768px - 480px  
- **Mobile:** < 480px

### Адаптивні класи
```css
@media (max-width: 768px) {
  /* Стилі для планшетів */
}

@media (max-width: 480px) {
  /* Стилі для мобільних */
}
```

## 🎭 Анімації

### Базові анімації
```css
.fade-in-up     /* Анімація появи знизу */
```

### Hover ефекти
- Кнопки: `translateY(-2px)` + тінь
- Картки: `translateY(-5px)` + тінь
- Зображення: `scale(1.05)`

## 🔧 Налаштування

### Додавання нових кольорів
1. Додайте змінну в `:root` в `src/index.css`
2. Використовуйте через `var(--назва-змінної)`

### Створення нових компонентів
1. Додайте стилі в `src/index.css`
2. Використовуйте консистентні назви класів
3. Додайте responsive стилі

## 📝 Правила

1. **Консистентність:** Використовуйте існуючі класи замість створення нових
2. **Кольори:** Завжди використовуйте CSS змінні замість хардкоду
3. **Responsive:** Завжди додавайте мобільні стилі
4. **Анімації:** Використовуйте плавні переходи (0.3s ease)
5. **Тіні:** Використовуйте стандартні тіні з глобальних стилів

## 🎯 Приклади

### Правильно
```jsx
<div className="card">
  <h3 className="section-title">Заголовок</h3>
  <p>Текст</p>
  <button className="btn-primary">Кнопка</button>
</div>
```

### Неправильно
```jsx
<div style={{background: '#ff6b35', borderRadius: '15px'}}>
  <h3 style={{color: '#333'}}>Заголовок</h3>
  <button style={{background: 'red'}}>Кнопка</button>
</div>
```
