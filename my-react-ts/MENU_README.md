# 🍔 Сторінка Меню Макдональдс

## Опис функціональності

Сторінка меню створена з використанням React TypeScript та включає наступні можливості:

### 📋 Основні функції

1. **Категорії меню:**
   - 🍔 Бургери (4 позиції)
   - 🥤 Напої (4 позиції)
   - 🍟 Гарніри (3 позиції)
   - 🍦 Десерти (3 позиції)
   - 🥞 Сніданки (2 позиції)

2. **Фільтрація та пошук:**
   - Перемикання між категоріями
   - Пошук по назві та опису товарів
   - Відображення кількості товарів у кожній категорії

3. **Інтерактивність:**
   - Кнопка "Додати" для кожного товару
   - Візуальна підтвердження додавання товару
   - Повідомлення про додавання до кошика

### 🎨 Дизайн

- **Сучасний UI** з градієнтами та тінями
- **Адаптивний дизайн** для мобільних пристроїв
- **Анімації** при наведенні та кліках
- **Кольорова схема** в стилі Макдональдс (червоний/помаранчевий)

### 📱 Адаптивність

- **Desktop:** Сітка з 3-4 колонками
- **Tablet:** Сітка з 2 колонками
- **Mobile:** Одна колонка з оптимізованими розмірами

### 🛠️ Технічні деталі

- **React 18** з TypeScript
- **CSS Grid** для макету
- **useState** для управління станом
- **Placeholder зображення** для демонстрації
- **Responsive breakpoints** для різних розмірів екрану

### 📂 Структура файлів

```
src/pages/
├── Menu.tsx          # Основний компонент меню
└── Menu.css          # Стилі для сторінки меню
```

### 🚀 Як використовувати

1. Перейдіть на сторінку `/menu`
2. Оберіть категорію або використайте пошук
3. Натисніть "Додати" для додавання товару до кошика
4. Насолоджуйтесь інтерактивним досвідом!
